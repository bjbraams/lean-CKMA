## Measures and their construction

[Mathematical scope](SYNOPSIS04.md#measures-and-their-construction).

### Mathlib

**Measurable spaces.** A measurable space is a set with a σ-algebra: a family of subsets containing the empty set and closed under complements and countable unions. A map is measurable when the preimage of every measurable set is measurable. On a fixed set the σ-algebras form a complete lattice under inclusion, and every family of sets generates a least σ-algebra containing it. A map \(f\) induces a Galois connection between the σ-algebras on its domain and those on its codomain (`MeasureTheory/MeasurableSpace/Defs.lean`, `MeasureTheory/MeasurableSpace/Basic.lean`).

Dynkin’s π–λ theorem is proved as an induction principle. A π-system, in the form used here, is a family closed under binary intersections whenever the intersection is nonempty. A Dynkin system contains the empty set and is closed under complements and under countable unions of pairwise disjoint sets. A predicate that holds on a π-system, and is preserved by complements and disjoint countable unions, holds on the generated σ-algebra (`MeasurableSpace.induction_on_inter`). The Dynkin system generated by a π-system is the generated σ-algebra (`MeasurableSpace.DynkinSystem.generateFrom_eq`) (`MeasureTheory/PiSystem.lean`).

Two finite measures that agree on a generating π-system and on the whole space are equal (`MeasureTheory.ext_of_generate_finite`, `MeasureTheory/Measure/Typeclasses/Finite.lean`). Two measures that agree on a generating π-system containing an increasing sequence of sets of finite measure with union the whole space are equal (`MeasureTheory.Measure.ext_of_generateFrom_of_iUnion`, `MeasureTheory/Measure/Restrict.lean`).

**Outer measures and the Carathéodory construction.** An outer measure assigns to every subset an extended nonnegative real, sends the empty set to zero, and is monotone and countably subadditive (`MeasureTheory/OuterMeasure/Defs.lean`). From any set function that sends the empty set to zero one obtains a greatest outer measure lying below it, by taking infima of sums over countable covers (`MeasureTheory/OuterMeasure/OfFunction.lean`).

A set is Carathéodory measurable for an outer measure \(m\) when \(m(t) = m(t \cap s) + m(t \setminus s)\) for every test set \(t\). These sets form a σ-algebra, and every set of outer measure zero is Carathéodory measurable (`OuterMeasure.isCaratheodory_of_measure_eq_zero`), so the restricted measure is complete (`MeasureTheory/OuterMeasure/Caratheodory.lean`). If a prescribed σ-algebra sits inside the Carathéodory σ-algebra, the outer measure restricts to a measure on it (`OuterMeasure.toMeasure`, `MeasureTheory/Measure/OuterMeasure.lean`).

Carathéodory's extension theorem is proved for an additive content on a semiring of sets that is σ-subadditive: every set of the generated σ-algebra is Carathéodory measurable for the induced outer measure, the induced outer measure agrees with the content on the semiring, and the content extends to a measure on the generated σ-algebra (`AddContent.isCaratheodory_inducedOuterMeasure`, `AddContent.measure`, `AddContent.measure_eq`, `MeasureTheory/OuterMeasure/OfAddContent.lean`). On a ring of sets a countably additive content is σ-subadditive (`MeasureTheory.isSigmaSubadditive_of_addContent_iUnion_eq_tsum`, `MeasureTheory/Measure/AddContent.lean`). Uniqueness of the extension in the σ-finite case follows from the extensionality theorem above.

**Measures.** A measure on a measurable space takes values in the extended nonnegative reals, vanishes on the empty set, and is countably additive on pairwise disjoint measurable sets. In the formalization a measure is an outer measure that is countably additive on measurable sets and coincides with the canonical extension of its restriction. The symbol \(\mu(s)\) therefore makes sense for an arbitrary set: it is the outer-measure value. Countable additivity is asserted for measurable sets, and countable subadditivity holds for all sets. Measures form a complete lattice and are closed under multiplication by extended nonnegative scalars (`MeasureTheory/Measure/MeasureSpaceDef.lean`).

A set is null measurable when it agrees almost everywhere with a measurable set. Equivalently, it differs from a measurable set by a null set. Null measurable sets form a σ-algebra. The completion of \(\mu\) is the same set function, read on that larger σ-algebra, and it is a complete measure: every subset of a null set is measurable (`Measure.completion`, `Measure.IsComplete`, `MeasureTheory/Measure/NullMeasurable.lean`).

\(\mu\) is absolutely continuous with respect to \(\nu\), written \(\mu \ll \nu\), when every \(\nu\)-null set is \(\mu\)-null. This is equivalent to inclusion of the almost-everywhere filters (`MeasureTheory/Measure/AbsolutelyContinuous.lean`). The two measures are mutually singular when some measurable set carries all the \(\nu\)-mass and none of the \(\mu\)-mass (`MeasureTheory/Measure/MutuallySingular.lean`). A measure is s-finite when it is a countable sum of finite measures, and σ-finite when the space is a countable union of sets of finite measure (`MeasureTheory/Measure/Typeclasses/SFinite.lean`).

The first Borel–Cantelli lemma is proved: if \(\sum_i \mu(s_i)\) is finite, then almost every point lies in only finitely many of the sets \(s_i\) (`MeasureTheory/OuterMeasure/BorelCantelli.lean`). The second lemma, for independent events, belongs to the probability library.

**Lebesgue and Stieltjes measures.** Lebesgue measure on \(\mathbb{R}\) is the additive Haar measure of the line, and it coincides with the Stieltjes measure of the identity function (`Real.volume_eq_stieltjes_id`). The product measure on \(\mathbb{R}^n\) is translation invariant. A linear endomorphism of \(\mathbb{R}^n\) multiplies Lebesgue measure by the absolute value of its determinant. The same scaling holds for any additive Haar measure on a finite-dimensional real vector space (`MeasureTheory/Measure/Lebesgue/Basic.lean`, `MeasureTheory/Measure/Lebesgue/EqHaar.lean`). Uniqueness of Haar measure up to a scalar, below, gives uniqueness of the normalized translation-invariant measure, and a locally finite measure on a σ-compact metric space is regular. Neither the nonmeasurable Vitali set nor the identification of the completed product \(\mathcal L^n\otimes\mathcal L^k\) with \(\mathcal L^{n+k}\) is stated.

A Stieltjes function on a conditionally complete dense linear order is monotone and right-continuous. It induces a Borel measure giving mass \(f(b) - f(a)\) to the half-open interval \((a, b]\) (`StieltjesFunction.measure_Ioc`); the measure is locally finite, and two Stieltjes functions with the same measure that agree at one point are equal (`StieltjesFunction.eq_of_measure_of_eq`). Any monotone function determines a Stieltjes function by passage to the right limit. On an order with a least element, a Stieltjes measure gives that point mass zero, so a Dirac mass there is not a Stieltjes measure (`MeasureTheory/Measure/Stieltjes.lean`). Locally finite measures on the line are determined by their values on intervals \((a,b]\) (`MeasureTheory.Measure.ext_of_Ioc`, `MeasureTheory/Constructions/BorelSpace/Order.lean`). The converse direction is proved for probability measures: the distribution function `ProbabilityTheory.cdf` of a probability measure on \(\mathbb R\) is a Stieltjes function whose measure is the given one (`ProbabilityTheory.measure_cdf`, `Mathlib/Probability/CDF.lean`); a distribution function for an arbitrary locally finite measure is not constructed.

**Haar measure (supporting; stated in Section 28).** On a locally compact Hausdorff group there exists a left Haar measure. The construction follows the compact-set covering argument. For a compact set \(K\) and a neighborhood \(U\) of the identity, \((K : U)\) is the least number of left translates of \(U\) needed to cover \(K\). Fixing a compact set \(K_0\) with nonempty interior, one considers the functions \(K\mapsto(K:U)/(K_0:U)\). Tychonoff’s theorem supplies a cluster point as \(U\) shrinks to the identity. The construction chooses such a cluster point; it does not assert convergence of the whole family of ratios. The resulting content extends to a regular left-invariant measure, normalized so that \(K_0\) has measure one. On compact sets, \(h(K)\) lies between the measure of the interior of \(K\) and the measure of \(K\) (`MeasureTheory/Measure/Haar/Basic.lean`).

Uniqueness holds up to a scalar, with the scalar depending on the two measures. Two left-invariant measures that are finite on compact sets integrate continuous compactly supported functions equally up to that scalar, and they agree up to the scalar on sets with compact closure and on open sets. Inner-regular left-invariant measures coincide up to a scalar, and so do regular ones. On a second-countable group, two Haar measures coincide up to a scalar. On a compact group, left-invariant measures coincide up to a scalar. Two Haar probability measures are equal (`MeasureTheory/Measure/Haar/Unique.lean`).

If \(\mu\) is an inner-regular left Haar measure, right translation by \(g^{-1}\) produces another left Haar measure, hence a scalar \(\Delta(g)\) with \(\mu(A g^{-1}) = \Delta(g)\,\mu(A)\). This modular character is a homomorphism to the positive reals and does not depend on the choice of \(\mu\). Continuity of \(\Delta\) is recorded as still to be proved (`MeasureTheory/Group/ModularCharacter.lean`).

**Synopsis entries.** Covered: 04.1–04.4 (Mathlib). Partly covered: 04.5 (Haar uniqueness, regularity, and determinant scaling; the Vitali set and the completed-product identity are absent), 04.6 (measure of a Stieltjes function and uniqueness; the distribution function is constructed only for probability measures).

## The integral and its convergence theorems

[Mathematical scope](SYNOPSIS04.md#the-integral-and-its-convergence-theorems).

### Mathlib

**Simple functions and the lower integral.** A simple function has finite range and measurable fibers. Every Borel measurable function with values in the extended nonnegative reals is the pointwise supremum of an increasing sequence of simple functions (`SimpleFunc.eapprox`). To prove a statement for every such measurable function, it is enough to check it on multiples of indicators and to know that it passes to sums and to suprema of increasing sequences (`Measurable.ennreal_induction`, `MeasureTheory/Function/SimpleFunc.lean`). This indicator-based induction is the nearest analogue of the functional monotone class theorem; the theorem itself, for a vector space of bounded functions closed under bounded increasing limits and containing a multiplicative class, is not stated. If the target of a measurable function is a separable subset of a metric space, simple functions with values in that subset approximate it pointwise (`MeasureTheory/Function/SimpleFuncDense.lean`), and integrable simple functions are dense in \(L^1\) (`MeasureTheory/Function/SimpleFuncDenseLp.lean`).

The lower Lebesgue integral takes values in the extended nonnegative reals. It is defined for functions into those reals, and the integral over a set is the integral against the restricted measure (`MeasureTheory/Integral/Lebesgue/Basic.lean`).

**Convergence theorems.** The monotone convergence theorem identifies the integral of the pointwise supremum of an increasing sequence of measurable extended-nonnegative functions with the supremum of the integrals. The same holds for an almost-everywhere measurable sequence, and for a supremum indexed by a countable directed set (`MeasureTheory/Integral/Lebesgue/Add.lean`). Integration of nonnegative functions commutes with countable sums (`MeasureTheory.lintegral_tsum`).

Fatou’s lemma, for an almost-everywhere measurable family of extended-nonnegative functions indexed along a countably generated filter, says that the integral of the liminf is at most the liminf of the integrals (`MeasureTheory/Integral/Lebesgue/Add.lean`).

The dominated convergence theorem for the lower integral: if measurable extended-nonnegative functions converge almost everywhere, and are dominated by a single function of finite integral, then the integrals converge to the integral of the limit. The almost-everywhere measurable variant is included, as is a version along a countably generated filter (`MeasureTheory/Integral/Lebesgue/DominatedConvergence.lean`). Under the same domination hypothesis, \(\int\|f_n-f\|\,d\mu\to0\) (`MeasureTheory.tendsto_lintegral_norm_of_dominated_convergence`, `MeasureTheory/Function/L1Space/HasFiniteIntegral.lean`).

**The Bochner integral.** The Bochner integral extends integration to functions with values in a Banach space. It is obtained by passing through the space of integrable equivalence classes, and a function that is not integrable is assigned integral zero. On integrable functions the integral is linear, depends only on the almost-everywhere class, and satisfies
\[
\Bigl\|\int f\, d\mu\Bigr\| \le \int \|f\|\, d\mu
\]
(`MeasureTheory/Integral/Bochner/Basic.lean`). A function is strongly measurable when it is an everywhere pointwise limit of simple functions, and finitely strongly measurable when those simple functions may be taken with support of finite measure. If the target is second countable, strong measurability agrees with measurability. If the measure is σ-finite, strong measurability agrees with finite strong measurability (`MeasureTheory/Function/StronglyMeasurable/Basic.lean`).

Dominated convergence for the Bochner integral: if almost-everywhere strongly measurable functions with values in a real normed space converge almost everywhere and are dominated in norm by one integrable real function, then the integrals converge to the integral of the limit. The result extends to countably generated filters, and to series whose norms are dominated by a summable family of integrable functions. If \(\sum_n\int\|f_n\|<\infty\), the integral of the sum is the sum of the integrals (`MeasureTheory.integral_tsum`, `MeasureTheory.hasSum_integral_of_summable_integral_norm`, `MeasureTheory/Integral/DominatedConvergence.lean`). A series whose \(L^p\) norms are summable, \(p\ge1\), converges absolutely almost everywhere and in \(L^p\) (`MeasureTheory.summable_norm_of_tsum_eLpNorm_ne_top`, `MeasureTheory.Lp.hasSum_coeFn_tsum`, `MeasureTheory/Function/LpSpace/InfiniteSum.lean`).

**Absolute continuity and distribution formulas.** For an integrable function and \(\varepsilon>0\) there is \(\delta>0\) such that sets of measure less than \(\delta\) carry integral less than \(\varepsilon\) (`MeasureTheory.exists_pos_setLIntegral_lt_of_measure_lt`, `MeasureTheory/Integral/Lebesgue/Basic.lean`), and the integral of \(|f|\) over \(\{|f|\ge R\}\) tends to zero (`MeasureTheory.MemLp.integral_indicator_norm_ge_le`, `MeasureTheory/Function/UniformIntegrable.lean`).

The layer-cake representation writes the integral of a nonnegative measurable function as the integral of its tail measures,
\[
\int f\, d\mu = \int_0^\infty \mu\{f \ge t\}\, dt,
\]
with a companion formula using strict inequality. More generally, if \(G\) vanishes at the origin and is absolutely continuous and increasing on the nonnegative reals, with derivative \(g\), then \(\int G \circ f\) equals the integral of the tail measures against \(g\) (`MeasureTheory/Integral/Layercake.lean`). The power case \(\int f^p\,d\mu=p\int_0^\infty t^{p-1}\mu\{f>t\}\,dt\) for \(p>0\) is `MeasureTheory.lintegral_rpow_eq_lintegral_meas_lt_mul` (`Analysis/SpecialFunctions/Pow/Integral.lean`).

**Jensen's inequality.** If \(\mu\) is a probability measure, \(f\) is integrable with values almost everywhere in a closed convex set \(s\) of a Banach space, and \(g\) is convex and continuous on \(s\) with \(g\circ f\) integrable, then \(g(\int f)\le\int g\circ f\) (`ConvexOn.map_integral_le`, `Analysis/Convex/Integral.lean`). The conditional form \(\varphi(\mathbb E[f\mid\mathcal G])\le\mathbb E[\varphi\circ f\mid\mathcal G]\) is proved for convex lower semicontinuous \(\varphi\) on a Banach space when \(f\) and \(\varphi\circ f\) are integrable (`ConvexOn.map_condExp_le`, `MeasureTheory/Function/ConditionalExpectation/CondJensen.lean`). The unconditional statement with an open interval and with \(\int\Phi(f)=+\infty\) allowed is not stated in this form.

**Riemann and Lebesgue integrals.** In the box-integral framework, a function on a rectangular box in \(\mathbb R^n\) that is bounded and continuous almost everywhere is Riemann integrable, and its Riemann integral equals the Lebesgue integral (`BoxIntegral.integrable_of_bounded_and_ae_continuous`, `AEContinuous.hasBoxIntegral`, `Analysis/BoxIntegral/Basic.lean`, `Analysis/BoxIntegral/Integrability.lean`). The converse half of Lebesgue's criterion, that a Riemann integrable function is continuous almost everywhere, is not stated.

Partly covered: 04.14 (closed convex domain and integrable \(\Phi(f)\) required; conditional form for lower semicontinuous \(\Phi\)), 04.15 (sufficiency of almost-everywhere continuity and equality of the integrals; necessity absent). Not covered: 04.65.

## Modes of convergence and approximation

[Mathematical scope](SYNOPSIS04.md#modes-of-convergence-and-approximation).

### Mathlib

Markov’s inequality, also called Chebyshev’s first inequality, states that for \(\varepsilon > 0\) and a nonnegative function,
\[
\mu\{x : \varepsilon \le f(x)\} \le \frac{1}{\varepsilon} \int f\, d\mu
\]
(`MeasureTheory/Integral/Lebesgue/Markov.lean`). The \(L^p\) form \(\varepsilon^p\mu\{\|f\|\ge\varepsilon\}\le\|f\|_p^p\) is `MeasureTheory.mul_meas_ge_le_pow_eLpNorm` (`MeasureTheory/Function/LpSeminorm/ChebyshevMarkov.lean`).

Egorov’s theorem: on a finite measure space, a sequence of measurable functions that converges almost everywhere converges uniformly off a set of arbitrarily small measure (`MeasureTheory/Function/Egorov.lean`).

Convergence in measure means that for every \(\varepsilon > 0\), the measure of the set where two functions differ by at least \(\varepsilon\) tends to zero. Almost-everywhere convergence on a finite measure space implies convergence in measure. A sequence that converges in measure has a subsequence that converges almost everywhere. On a finite measure space, convergence in measure is equivalent to every subsequence having a further subsequence converging almost everywhere (`MeasureTheory.exists_seq_tendstoInMeasure_atTop_iff`). For \(0<p\le\infty\), convergence in \(L^p\) implies convergence in measure (`MeasureTheory/Function/ConvergenceInMeasure.lean`). No metric or uniform structure for convergence in measure on the space of measurable functions is constructed.

A family is uniformly integrable (`MeasureTheory.UnifIntegrable`) when the \(L^p\) norm of its restriction to a set of small measure is uniformly small. In the probabilistic form (`MeasureTheory.UniformIntegrable`) one also asks for a uniform bound on the \(L^p\) norms. Vitali’s convergence theorem, for a finite measure and an exponent \(1 \le p < \infty\): for functions in \(L^p\) and a limit in \(L^p\), convergence in \(L^p\) is equivalent to uniform integrability together with convergence in measure (`MeasureTheory.tendstoInMeasure_iff_tendsto_Lp_finite`). Almost-everywhere convergence and uniform integrability already give \(L^p\) convergence under the same hypotheses, and a family uniformly integrable in the probabilistic sense has its limit in measure in \(L^p\) (`MeasureTheory.UniformIntegrable.memLp_of_tendstoInMeasure`, `MeasureTheory/Function/UniformIntegrable.lean`). On an arbitrary measure space, a family is uniformly tight in \(L^p\) when its \(L^p\) mass outside some set of finite measure is uniformly small, and Vitali's theorem holds with uniform integrability and uniform tightness together (`MeasureTheory.UnifTight`, `MeasureTheory.tendstoInMeasure_iff_tendsto_Lp`, `MeasureTheory/Function/UnifTight.lean`).

Vitali–Carathéodory approximation, in a strict form that assumes the measure is σ-finite and regular: an integrable real function lies strictly below an extended-real-valued lower-semicontinuous function, and strictly above an extended-real-valued upper-semicontinuous function, finite almost everywhere, whose integrals are arbitrarily close to its own (`MeasureTheory/Integral/Bochner/VitaliCaratheodory.lean`).

### TauCeti

Lusin's theorem is proved in its closed-set form. If \(\mu\) is weakly regular, \(f\) is measurable (or almost-everywhere measurable) with values in a second-countable topological space, \(s\) is measurable with \(\mu(s)<\infty\), and \(\varepsilon>0\), then there is a closed \(F\subseteq s\) with \(\mu(s\setminus F)<\varepsilon\) on which \(f\) is continuous; the same holds for (almost-everywhere) strongly measurable maps into a pseudometrizable space, without second countability ([Lusin](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Function/Lusin.lean), `Measurable.exists_isClosed_measure_sdiff_lt_continuousOn`, `AEMeasurable.exists_isClosed_measure_sdiff_lt_continuousOn`, `MeasureTheory.AEStronglyMeasurable.exists_isClosed_measure_sdiff_lt_continuousOn`). Measurability for the completion is almost-everywhere measurability. A finite Radon measure on a locally compact Hausdorff space is weakly regular in Mathlib, and inner regularity by compact sets then yields the compact set of the textbook statement.

TauCeti proves Vitali's convergence theorem for maps into a second-countable pseudometric space, stated through the distances to the limit ([Vitali](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Function/UniformIntegrable.lean), `TauCeti.tendsto_eLpNorm_dist_iff_tendstoInMeasure_and_unifIntegrable`).

**Synopsis entries.** Covered: 04.16, 04.17, 04.19, 04.21 (Mathlib), 04.20 (TauCeti; closed-set form, with the compact form by inner regularity). Not covered: 04.18, 04.22.

## Products, image measures, and parameter integrals

[Mathematical scope](SYNOPSIS04.md#products-image-measures-and-parameter-integrals).

### Mathlib

**Product measures.** If \(\mu\) and \(\nu\) are s-finite, their product is the s-finite measure on the product space determined by
\[
(\mu \otimes \nu)(s) = \int \nu\{y : (x, y) \in s\}\, d\mu(x)
\]
for measurable \(s\), and \((\mu \otimes \nu)(A \times B) = \mu(A)\,\nu(B)\) for measurable rectangles. For σ-finite factors it is the unique measure with this property on rectangles (`MeasureTheory.Measure.prod_eq`, `MeasureTheory/Measure/Prod.lean`).

Tonelli’s theorem: for a measurable function on a product of s-finite measure spaces, with values in the extended nonnegative reals, the section integrals are measurable,
\[
\int f\, d(\mu \otimes \nu) = \iint f(x, y)\, d\nu(y)\, d\mu(x),
\]
and the two orders of integration agree (`MeasureTheory/Measure/Prod.lean`).

Fubini’s theorem: if \(f\) is integrable on a product of s-finite spaces and takes values in a real normed space, then for almost every \(x\) the slice \(y \mapsto f(x, y)\) is integrable, \(x \mapsto \int \|f(x, y)\|\, d\nu(y)\) is integrable, and the integral equals the iterated integral in either order (`MeasureTheory.integrable_prod_iff`, `MeasureTheory.integral_prod`, `MeasureTheory.integral_prod_swap`). For a continuous compactly supported integrand there is a Fubini theorem that does not require σ-finiteness of the measures (`MeasureTheory.integral_integral_swap_of_hasCompactSupport`, `MeasureTheory/Integral/Prod.lean`). The version for the completed product measure is not stated.

**Image measures and kernels.** For a measurable map \(T\), integration against the image measure is integration of the composite, for nonnegative measurable and for integrable integrands (`MeasureTheory.lintegral_map`, `MeasureTheory/Integral/Lebesgue/Map.lean`; `MeasureTheory.integral_map`, `MeasureTheory/Integral/Bochner/Basic.lean`). For an s-finite measure \(\mu\) and an s-finite kernel \(\kappa\), the measure \(\mu\otimes\kappa\) on the product satisfies \((\mu\otimes\kappa)(s)=\int\kappa(x,\{y:(x,y)\in s\})\,d\mu(x)\) and integrates nonnegative measurable functions iteratively (`MeasureTheory.Measure.compProd_apply`, `MeasureTheory.Measure.lintegral_compProd`, `Mathlib/Probability/Kernel/Composition/MeasureCompProd.lean`). Composition of kernels and of a kernel with a measure is also developed (`Mathlib/Probability/Kernel/Composition/Comp.lean`, `Mathlib/Probability/Kernel/Composition/MeasureComp.lean`).

**Differentiation under the integral.** If \(F(x_0,\cdot)\) is integrable, \(F(x,\cdot)\) is almost-everywhere strongly measurable for \(x\) near \(x_0\), and \(x\mapsto F(x,a)\) is differentiable on a neighborhood of \(x_0\) for almost every \(a\), with derivative dominated there by an integrable function, then \(x\mapsto\int F(x,a)\,d\mu(a)\) is differentiable at \(x_0\) with derivative \(\int\partial_xF(x_0,a)\,d\mu(a)\) (`hasDerivAt_integral_of_dominated_loc_of_deriv_le`, `Analysis/Calculus/ParametricIntegral.lean`).

**Synopsis entries.** Covered: 04.23, 04.24, 04.26–04.28 (Mathlib). Partly covered: 04.25 (product of s-finite measures; the completed-product version is absent). Not covered: 04.66.

## Signed measures, variation, and densities

[Mathematical scope](SYNOPSIS04.md#signed-measures-variation-and-densities).

### Mathlib

A vector measure with values in a topological additive monoid is countably additive on measurable sets, in the sense of convergent sums, and sends the empty set and every nonmeasurable set to zero. A signed measure is a real-valued vector measure, and a complex measure is a complex-valued one (`MeasureTheory/VectorMeasure/Defs.lean`). Every complex measure is \(s + it\) for signed measures \(s\) and \(t\), and complex measures are equivalent to pairs of signed measures (`MeasureTheory/Measure/Complex.lean`).

The Hahn decomposition theorem splits a signed measure into complementary measurable sets, one positive and one negative for the measure, and the symmetric difference of two such decompositions is null (`SignedMeasure.exists_compl_positive_negative`, `SignedMeasure.of_symmDiff_compl_positive_negative`, `MeasureTheory/VectorMeasure/Decomposition/Hahn.lean`). An unsigned form compares two finite positive measures: some measurable set is such that the second measure dominates the first on its subsets, and the first dominates the second on subsets of the complement (`MeasureTheory/Measure/Decomposition/Hahn.lean`).

The Jordan decomposition writes a signed measure uniquely as the difference of two mutually singular finite positive measures, and the total variation is defined as their sum (`MeasureTheory/VectorMeasure/Decomposition/Jordan.lean`).

The Lebesgue decomposition theorem, for σ-finite positive measures \(\mu\) and \(\nu\), writes \(\mu\) as the sum of a measure singular to \(\nu\) and a measure with a measurable density with respect to \(\nu\). The singular part and the density are unique in that representation (`MeasureTheory/Measure/Decomposition/Lebesgue.lean`). The same decomposition, with an integrable density and with uniqueness of both parts, holds for a signed measure against a σ-finite positive measure, by applying the positive result to the Jordan parts (`SignedMeasure.singularPart_add_withDensity_rnDeriv_eq`, `SignedMeasure.eq_singularPart`, `SignedMeasure.eq_rnDeriv`). For a complex measure the decomposition into a singular part and an integrable density is proved through the real and imaginary parts (`ComplexMeasure.singularPart_add_withDensity_rnDeriv_eq`), without a uniqueness statement (`MeasureTheory/VectorMeasure/Decomposition/Lebesgue.lean`).

The Radon–Nikodym theorem is the absolutely continuous case. When a Lebesgue decomposition exists, \(\mu \ll \nu\) if and only if \(\mu\) is \(\nu\) weighted by the Radon–Nikodym derivative. For σ-finite measures the decomposition exists, so the theorem applies. Integrating the derivative over a measurable set recovers the measure of that set. There is a signed-measure form: a signed measure absolutely continuous with respect to a σ-finite measure is the measure with density its integrable Radon–Nikodym derivative (`SignedMeasure.withDensityᵥ_rnDeriv_eq`) (`MeasureTheory/Measure/Decomposition/RadonNikodym.lean`, `MeasureTheory/VectorMeasure/Decomposition/RadonNikodym.lean`). The chain rule \(\frac{d\lambda}{d\mu}=\frac{d\lambda}{d\nu}\frac{d\nu}{d\mu}\) for σ-finite measures with \(\lambda\ll\nu\) (`MeasureTheory.Measure.rnDeriv_mul_rnDeriv`) and the change of measure \(\int g\,d\nu=\int g\,\frac{d\nu}{d\mu}\,d\mu\) (`MeasureTheory.Measure.lintegral_rnDeriv_mul`, `MeasureTheory.integral_rnDeriv_smul`) are in the same file.

The variation of a vector measure with values in a normed group is the supremum, over finite measurable partitions of a set, of the sums of the norms of the values; it is a positive measure dominating the norm of the vector measure, and for a signed measure it coincides with the total variation built from the Jordan decomposition (`SignedMeasure.totalVariation_eq_variation`) (`MeasureTheory/VectorMeasure/Variation/Defs.lean`, `MeasureTheory/VectorMeasure/Variation/Basic.lean`, `MeasureTheory/VectorMeasure/Variation/SignedMeasure.lean`). The semivariation, the supremum of the variations of the scalar images under functionals of norm at most one, satisfies \(\|\mu(s)\|\le\operatorname{semivar}\mu(s)\le2\sup_{t\subseteq s}\|\mu(t)\|\), so every vector measure in a normed space is bounded (`MeasureTheory/VectorMeasure/Variation/Semivariation.lean`). A vector-valued function integrable for the variation can be integrated against a vector measure through a continuous bilinear pairing, with \(\|\int f\,d\mu\|\le\|B\|\int\|f\|\,d|\mu|\) for the pairing \(B\) (`VectorMeasure.norm_integral_le_integral_norm`); the measure with density \(f\) for this integral has variation \(\|f\|\) times the variation of \(\mu\), and for a positive measure \(\mu\) and an integrable \(f\) the variation of \(f\mu\) is \(\|f\|\mu\) (`MeasureTheory.Measure.variation_withDensityᵥ`) (`MeasureTheory/VectorMeasure/Integral.lean`, `MeasureTheory/VectorMeasure/WithDensityVec.lean`). Products of vector measures exist when one factor has finite variation, with Fubini theorems when both do (`MeasureTheory/VectorMeasure/Prod.lean`). A Banach-valued function of bounded variation on a dense linear order with compact intervals determines a vector Stieltjes measure, with integration by parts formulas using left and right limits (`MeasureTheory/VectorMeasure/BoundedVariation.lean`, `MeasureTheory/VectorMeasure/IntegrationByParts.lean`). The total variation distance of two vector measures is the variation of their difference on the whole space; for finite positive measures it is expressed through the Radon–Nikodym derivative and the singular part, and through a Hahn decomposition (`MeasureTheory/VectorMeasure/TotalVariation.lean`, `MeasureTheory/Measure/TotalVariation/Defs.lean`, `MeasureTheory/Measure/TotalVariation/Basic.lean`). The polar decomposition \(d\nu=u\,d|\nu|\) with \(|u|=1\) is not stated.

## $L^p$ spaces and the analytic operations on them

[Mathematical scope](SYNOPSIS04.md#lp-spaces-and-the-analytic-operations-on-them).

### Mathlib

Hölder’s inequality for the lower integral of extended-nonnegative functions, with conjugate exponents \(p\) and \(q\), bounds the integral of a product by the product of the \(L^p\) and \(L^q\) integrals. A weighted form covers a finite family of functions whose exponents sum to one. Minkowski’s inequality gives the triangle inequality in \(L^p\) for \(p \ge 1\) (`MeasureTheory/Integral/MeanInequalities.lean`).

Two strongly measurable functions are identified when they agree almost everywhere. The resulting space of classes carries the pointwise linear structure and the almost-everywhere partial order of the target (`MeasureTheory/Function/AEEqFun.lean`).

For an extended exponent \(p\), the space \(L^p\) consists of those classes whose \(L^p\) seminorm is finite. At a finite positive exponent the seminorm is the \(p\)-th root of the integral of the \(p\)-th power of the norm. At the exponent \(\infty\) it is the essential supremum of the norm (`MeasureTheory/Function/LpSpace/Basic.lean`, `MeasureTheory/Function/EssSup.lean`). For \(1 \le p \le \infty\), and for a Banach space of values, \(L^p\) is a Banach space (`MeasureTheory/Function/LpSpace/Complete.lean`), and \(L^2\) is an inner product space with the integral inner product (`MeasureTheory.L2.innerProductSpace`, `MeasureTheory/Function/L2Space.lean`).

For \(p < \infty\), simple functions are dense in \(L^p\). A predicate on \(L^p\), or on the integrable functions, may be proved by checking it on simple functions and passing to the limit (`MeasureTheory/Function/SimpleFuncDenseLp.lean`).

Continuous functions are dense in the same range of exponents. On a normal space, with a weakly regular measure, bounded continuous functions are dense in \(L^p\) for \(p < \infty\). On a locally compact Hausdorff space, with a regular measure, continuous functions of compact support are dense (`MeasureTheory.MemLp.exists_hasCompactSupport_eLpNorm_sub_le`, `MeasureTheory/Function/ContinuousMapDense.lean`).

A continuous bilinear map of Banach spaces induces a bilinear map on a Hölder triple of \(L^p\) spaces. When the exponents are conjugate, integration against that bilinear map defines a continuous pairing of \(L^p\) with \(L^q\). Taking the bilinear map to be the evaluation of the bidual embedding, one obtains a map from \(L^p\) of the dual into the dual of \(L^q\) (`MeasureTheory/Function/Holder.lean`).

For a family \(\varphi_i\ge0\) of integral one whose supports shrink to the origin, \((\varphi_i*g)(x)\to g(x_0)\) whenever \(g\) is continuous at \(x_0\) and \(x\to x_0\) (`convolution_tendsto_right`, `Analysis/Convolution.lean`); this is the pointwise and locally uniform part of the approximate-identity theorem.

For conjugate exponents \(q,q'\), if \(h\in L^q\) satisfies \(|\int hg\,d\mu|\le C\|g\|_{q'}\) for every simple \(g\), then \(\|h\|_q\le C\); for \(q<\infty\) on an arbitrary measure space, and for \(q=\infty\) on a σ-finite space ([norming](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Function/Lp/Duality.lean), `MeasureTheory.MemLp.eLpNorm_le_of_forall_enorm_integral_mul_le_of_ne_top`, `MeasureTheory.MemLp.eLpNorm_le_of_forall_enorm_integral_mul_le`). Minkowski's integral inequality \(\bigl\|\int f(\cdot,y)\,d\nu(y)\bigr\|_{L^p(\mu)}\le\int\|f(\cdot,y)\|_{L^p(\mu)}\,d\nu(y)\), \(p\ge1\), is proved for nonnegative jointly measurable integrands on a σ-finite times s-finite product ([Minkowski](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Integral/MinkowskiIntegral.lean), `TauCeti.lintegral_Lp_lintegral_le`). ## Differentiation and Euclidean integration formulas

[Mathematical scope](SYNOPSIS04.md#differentiation-and-euclidean-integration-formulas).

### Mathlib

**Change of variables.** Let \(\mu\) be an additive Haar measure on a finite-dimensional real vector space, and let \(f\) be injective and differentiable on a measurable set \(s\). Then \(f(s)\) is measurable and
\[
\mu(f(s)) = \int_s \lvert \det Df(x) \rvert\, d\mu(x).
\]
The derivative is almost everywhere measurable. The same Jacobian factor implements the change of variables in the lower integral and in the Bochner integral (`MeasureTheory.lintegral_image_eq_lintegral_abs_det_fderiv_mul`, `MeasureTheory.integral_image_eq_integral_abs_det_fderiv_smul`). A null set is sent to a null set. If the derivative is nowhere invertible on \(s\), then \(f(s)\) has measure zero. One-dimensional statements, for monotone and antitone maps, use the ordinary derivative in place of the determinant (`MeasureTheory/Function/Jacobian.lean`, `MeasureTheory/Function/JacobianOneDim.lean`). These hypotheses are weaker than those of the \(C^1\)-diffeomorphism statement.

**Polar coordinates.** For a finite-dimensional real normed space with additive Haar measure \(\mu\), the map \(x\mapsto(x/\|x\|,\|x\|)\) carries \(\mu\) on \(E\setminus\{0\}\) to the product of the sphere measure `Measure.toSphere` and the radial measure \(r^{d-1}\,dr\) (`MeasureTheory.Measure.measurePreserving_homeomorphUnitSphereProd`); the integral formula is stated for radial functions (`MeasureTheory.integral_fun_norm_addHaar`) (`MeasureTheory/Constructions/HaarToSphere.lean`). For nonnegative measurable functions the polar formula follows from this measure identity and Tonelli's theorem.

**Covering and differentiation (supporting; the theorems are stated in Section 05).** The topological Vitali covering theorem extracts, from a family of balls of bounded radii, a disjoint subfamily such that every ball of the original family is contained in the five-times enlargement of some selected ball. The measurable form, for a fine family of closed sets that occupy a definite fraction of a ball of comparable size, extracts a disjoint subfamily covering almost every point of the set at which the family is fine (`MeasureTheory/Covering/Vitali.lean`).

The Besicovitch covering theorem applies in a metric space that admits no satellite configuration of \(N+1\) balls, a condition satisfied by finite-dimensional real vector spaces. From any family of balls of bounded radii one can extract \(N\) disjoint subfamilies whose union covers every center. The measurable form covers almost every point by disjoint admissible balls, and small balls form a Vitali family (`MeasureTheory/Covering/Besicovitch.lean`).

Differentiation of measures along a Vitali family, on a second-countable metric space: for almost every point, as the sets of the family shrink to the point, the ratio of two measures tends to the Radon–Nikodym derivative. Almost every point of a measurable set is a density point along the family, and the average oscillation of an integrable function tends to zero (`MeasureTheory/Covering/Differentiation.lean`). For a locally finite, uniformly locally doubling measure on a σ-compact metric space, the same density statement holds along sequences of closed balls containing the point, without requiring the centers to be fixed (`MeasureTheory/Covering/DensityTheorem.lean`).

On the line, if a Banach-valued function is locally integrable, then for almost every \(x\) the indefinite integral \(\int_c^x f\) is differentiable at \(x\) with derivative \(f(x)\). The same holds almost everywhere on a compact interval when \(f\) is integrable on that interval (`MeasureTheory/Integral/IntervalIntegral/LebesgueDifferentiationThm.lean`).

## Radon measures, weak convergence, and structural extensions

[Mathematical scope](SYNOPSIS04.md#radon-measures-weak-convergence-and-structural-extensions).

### Mathlib

**Contents and regularity.** A content on compact sets takes values in the extended nonnegative reals and is additive on disjoint sets in its domain, subadditive, and monotone. Its inner content on an open set is the supremum of the content of compact subsets. The associated outer measure of a set is the infimum of the inner content of open sets containing it. Restriction to the Borel sets yields a Borel measure. The construction is given for \(R_1\) spaces. The measure is outer regular by design, and it is regular when the space is locally compact (`MeasureTheory/Measure/Content.lean`).

Several regularity predicates are distinguished, because they diverge outside σ-compact spaces (`MeasureTheory/Measure/Regular.lean`).

- Outer regular: every measurable set is approximated from above by open sets.
- Weakly regular: outer regular, and every open set is approximated from inside by closed sets. A finite measure on a pseudometrizable Borel space is weakly regular, and so is a locally finite measure on a second-countable pseudometrizable Borel space.
- Regular: finite on compact sets, outer regular, and every open set is approximated from inside by compact sets. A locally finite measure on a σ-compact pseudometrizable space is regular (`MeasureTheory.Measure.Regular.of_sigmaCompactSpace_of_isLocallyFiniteMeasure`).
- Inner regular: every measurable set is approximated from inside by compact sets. A companion predicate asks this only for measurable sets of finite measure, and for σ-finite measures the two agree.

A finite Borel measure on a second-countable, completely pseudometrizable space, in particular on a Polish space, is inner regular for compact sets, hence tight (`MeasureTheory/Measure/RegularityCompacts.lean`). A finite inner-regular measure is tight. A set of measures is tight when, for every \(\varepsilon > 0\), one compact set captures all but at most \(\varepsilon\) of the mass of every measure in the set. These definitions are in `MeasureTheory/Measure/Tight.lean`.

**Riesz representation.** The Riesz–Markov–Kakutani theorem is proved for a locally compact Hausdorff space. A positive real-linear functional on the continuous real functions of compact support is integration against a regular Borel measure, unique among regular Borel measures (`RealRMK.rieszMeasure`, `RealRMK.integral_rieszMeasure`, `RealRMK.integralPositiveLinearMap_inj`). The corresponding statement for additive functionals with values in the nonnegative reals is reduced to the real-linear case (`MeasureTheory/Integral/RieszMarkovKakutani/Real.lean`, `MeasureTheory/Integral/RieszMarkovKakutani/NNReal.lean`). The argument is the one in Rudin’s *Real and Complex Analysis*, built from a content on compact sets. The complex-linear version, and the representation of the dual of \(C_0(X)\) by signed or complex measures, are not stated.

**Hausdorff measure (supporting; stated in Section 37).** Hausdorff measure of dimension \(d\) is obtained from the metric outer measures that charge a set by at most the \(d\)-th power of its diameter, once the diameter is smaller than a scale \(\delta\), and then by taking the supremum over \(\delta\). Carathéodory’s criterion makes this a Borel measure. If \(d < d'\), then either the \(d\)-dimensional measure of a set is infinite or the \(d'\)-dimensional measure is zero. Hausdorff dimension is defined from that dichotomy. The same construction accepts a general gauge of the diameter, or a general set function, in place of the power of the diameter (`MeasureTheory/Measure/Hausdorff.lean`).

**Weak convergence (supporting; the portmanteau and Prokhorov theorems are stated in Section 06A).** Finite measures, and probability measures, carry the topology of weak convergence: the coarsest topology making integration of every bounded continuous nonnegative function continuous. A net of finite measures converges weakly if and only if the integrals of all such functions converge, and likewise for probability measures and bounded continuous random variables (`MeasureTheory/Measure/FiniteMeasure.lean`, `MeasureTheory/Measure/ProbabilityMeasure.lean`).

The portmanteau implications are proved separately (`MeasureTheory/Measure/Portmanteau.lean`). Write (T) for weak convergence, (C) for the limsup inequality on closed sets, (O) for the liminf inequality on open sets, and (B) for convergence on Borel sets whose boundary is null.

- (C) and (O) are equivalent.
- (O) implies (B).
- (B) implies (C).
- (T) implies (C) when closed sets can be approximated pointwise from above by decreasing sequences of bounded continuous functions. Metrizable and pseudo-metrizable spaces satisfy that approximation property.
- For a sequence of Borel probability measures, (O) implies (T), and (C) implies (T).
- If the measures are tight, the closed-set inequality may be weakened to a compact-set inequality and still yields weak convergence.
- If a sequence of probability measures converges on every member of a π-system, and the π-system contains arbitrarily small neighborhoods of every point, then the sequence converges weakly.

The space of probability measures on a compact Hausdorff space is compact. The proof uses ultrafilters and the Riesz–Markov–Kakutani theorem, and it does not assume second-countability or metrizability. On a Hausdorff Borel space, the full set of probability measures satisfying \(\mu(K_n^c)\le u_n\) for every \(n\), where the \(K_n\) are compact and \(u_n\to0\), is compact if the space is normal or the \(K_n\) are increasing. An arbitrary subset of this set need not itself be compact. A tight set of probability measures has compact closure. In a complete second-countable metric space the converse holds: a set of probability measures with compact closure is tight. The finite-measure versions also require a uniform bound on total masses (`MeasureTheory/Measure/Prokhorov.lean`).

The Lévy–Prokhorov metric is also constructed. On a separable metric Borel space its topology on probability measures agrees with weak convergence (`MeasureTheory/Measure/LevyProkhorovMetric.lean`, `LevyProkhorov.eq_convergenceInDistribution`). The set of all measures on a measurable space, probabilities included, is itself a measurable space, and the assignment is a monad on measurable spaces (`MeasureTheory/Measure/GiryMonad.lean`).

**Polish spaces and analytic sets.** A standard Borel space is a measurable space isomorphic to the Borel σ-algebra of some Polish topology. A set is analytic when it is a continuous image of a Polish space; equivalently, it is empty or a continuous image of the Baire space \(\mathbb{N}^{\mathbb{N}}\). Continuous images of analytic sets are analytic, and in a Polish space every Borel set is analytic (`MeasureTheory/Constructions/Polish/Basic.lean`).

Lusin’s separation theorem: two disjoint analytic sets are contained in complementary Borel sets. The Lusin–Souslin theorem: a continuous injective image of a Borel subset of a Polish space is Borel, and a continuous injection from a Polish space is a measurable embedding for the Borel σ-algebras. A measurable injection from a standard Borel space into a countably separated measurable space is a measurable embedding as well (`MeasureTheory/Constructions/Polish/Basic.lean`).

## Conditional integration, interpolation, and size of sets

### Mathlib

Mathlib characterizes uniform integrability through uniform absolute continuity together with an \(L^p\) bound (`MeasureTheory.UniformIntegrable`, `MeasureTheory/Function/UniformIntegrable.lean`); the de la Vallée Poussin criterion by a superlinear convex function is not stated.

### TauCeti

The following interpolation results support the theorems stated in Section 26. TauCeti proves diagonal Marcinkiewicz interpolation between two finite weak-type exponents; the off-diagonal interpolation theorem is not included ([interpolation](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Integral/Marcinkiewicz/General.lean)).

TauCeti proves the Riesz–Thorin theorem: a complex-linear operator on simple functions, bounded from \(L^{p_0}\) to \(L^{q_0}\) with norm \(M_0\) and from \(L^{p_1}\) to \(L^{q_1}\) with norm \(M_1\) (source exponents in \((0,\infty]\), target exponents in \([1,\infty]\)), satisfies \(\|Tf\|_{q_\theta}\le M_0^{1-\theta}M_1^\theta\|f\|_{p_\theta}\) for the interpolated exponents, with the target measure σ-finite when \(q_\theta=\infty\) ([Riesz–Thorin](https://github.com/TauCetiProject/TauCeti/blob/5cdecf40e99d5a5ad0833afff31f5b007d68a149/TauCeti/MeasureTheory/Integral/RieszThorin.lean), `TauCeti.eLpNorm_le_rpow_mul_rpow_mul_eLpNorm`, `TauCeti.eLpNorm_le_rpow_mul_rpow_mul_eLpNorm_of_ne_top`).
